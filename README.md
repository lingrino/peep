# peep

peep is a performance focused macos quick look extension for previewing markdown and coding languages. peep has zero dependencies

```sh
brew install --cask lingrino/tap/peep
```

- supports markdown, ~60 languages, jupyter notebooks, sqlite dbs, zip/tar/gz archives
- sidebar showing markdown headings or code declarations
- support for ⌘F file search
- button for copying file path
