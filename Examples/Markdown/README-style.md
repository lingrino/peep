## Install

```sh
brew install example-project
```

## Usage

```console
$ example --input data.csv --format json
{"rows": 42}
```

| Flag | Default | Description |
|---|---|---|
| `--input` | stdin | File to read |
| `--format` | `text` | `text`, `json` or `yaml` |
| `--quiet` | off | Suppress progress output |
